# Traceability matrix

Requirement → case → spec. Generated by [`scripts/traceability.py`](../scripts/traceability.py) from the three places these already live: the rules table in the application's README, the case exports in [`docs/test-cases/`](test-cases/), and the test titles in [`tests/`](../tests/). It is not maintained by hand, because a hand-kept fourth copy starts correct and drifts — which is DEF-15 one layer up.
